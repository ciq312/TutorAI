## Найденные ограничения

В `facts` модель привязала класс и цель из профиля к источнику занятия, хотя
этот источник их не содержит. После прогона инструкция уточнена: профиль задаёт
адаптацию, а facts должны подтверждаться только текстами источников. Все три
живых ответа получены до этого уточнения; его эффект ещё не оценён повторно.
Проверка диапазона номеров источников не доказывает поддержку каждого утверждения.

Первый запрос с таймаутом 90 секунд завершился `provider_timeout`. С таймаутом
180 секунд и low thinking все три запроса завершились. Эти параметры заданы
в конфигурации по умолчанию; задержка требует оценки при повседневной работе.
Gemini 2.5 Flash для настроенного ключа вернул 404 с рекомендацией 3.8 Flash;
поэтому модель по умолчанию обновлена. Тариф и доступность зависят от проекта.

Ollama проверен HTTP-моками, без запуска настоящей локальной модели.
