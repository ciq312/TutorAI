# My Tutor AI — frontend

React + TypeScript + Vite + Tailwind CSS v4. Тёмная графитовая тема с лавандовыми акцентами.

## Запуск

```sh
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173. Для разработки подходит Node.js 22.18+ или 24+.

Интерфейс работает только с API. Встроенные демоданные и фиктивные ответы удалены. Запустите backend на порту 8000: Vite перенаправляет `/api` на него. При пустой базе показываются пустые состояния; существующие записи базы автоматически не удаляются.

После обновления backend необходимо применить миграцию `0003_lesson_workspace`: `alembic upgrade head` в окружении backend. Docker Compose применяет миграции при старте API. Рабочую базу агент автоматически не обновлял.

## Основной рабочий цикл

1. В календаре (неделя по умолчанию, доступен месяц) создайте занятие для ученика. Можно создать сразу 4 или 8 еженедельных занятий. Это отдельные записи, а не бесконечное правило повторения.
2. Откройте карточку занятия. В «Подготовке» доступны бриф, план, предыдущее ДЗ и сохранённые решения.
3. В «Итогах» запишите фактически пройденное, выполнение прошлого ДЗ и трудности. Сохранение явно отмечает занятие проведённым; прошедшая дата сама этого не делает.
4. В «Новом ДЗ» задайте время и пожелания: например, пять номеров на знаки, два с подвохом. Отредактируйте задания и ответы, сохраните правки, затем примите ДЗ.
5. В «Для ученика» находится только принятое ДЗ без решений. Его можно скопировать для самостоятельной отправки.
6. В «Следующем уроке» подготовьте план и назначьте новое занятие. План копируется в подготовку первой новой записи для того же ученика.
7. В «Фидбеке» подготовьте и отредактируйте текст для ученика или родителя.

Длительность, время подготовки, статус, планы, черновики, ответы, источники и предупреждения сохраняются в записи занятия в backend. Принятое ДЗ хранится отдельно от черновика. Перенос и обратимая отмена доступны в карточке. Отменённые занятия исключены из retrieval-контекста.

## Дополнительные экраны

- **Чат:** свободные вопросы по выбранному ученику. Диалоги разделены по ученикам и сохраняются при переключении вкладок до перезагрузки страницы. Ответ чата сам по себе не меняет записи занятий.
- **Ученики:** поиск, создание, редактирование профиля и история занятий. Все действия с материалами открывают общую карточку занятия.
- **Настройки:** локальные предпочтения времени подготовки и напоминания, текущий часовой пояс, статус будущих интеграций.

## Границы автоматизации

Telegram, Google Calendar и серверный планировщик ещё не подключены. Настройка «подготовить за N минут» сохраняется, но не запускает генерацию. Напоминания и отправка сообщений не выполняются. Сейчас подготовка запускается вручную в карточке; интерфейс это явно показывает. Предпочтения устройства не являются серверным расписанием.

Источники и ограничения контекста отображаются рядом с материалом. Существование ссылки не гарантирует правильность утверждения. Проверяйте факты, условия и решения до принятия ДЗ.

## Структура

- `src/App.tsx` — композиция экранов и диалога.
- `src/pages/` — календарь, занятие, чат, ученики и настройки.
- `src/components/` — reusable UI по областям: calendar, lessons, chat, students, settings, layout.
- `src/hooks/useWorkspace.ts` — навигация и записи учеников/занятий.
- `src/hooks/useLessonWorkspace.ts` — генерация, правки и принятие материалов занятия.
- `src/hooks/useCalendar.ts`, `useChat.ts`, `useStudentProfile.ts`, `usePreferences.ts` — отдельные рабочие сценарии.
- `src/services/tutorApi.ts` — endpoint-контракты, payload mapping и полная пагинация списков.
- `src/api.ts` — HTTP-транспорт и ошибки.
- `src/types.ts`, `src/utils/` — типы и чистые функции.

Tailwind подключён через `@tailwindcss/vite`. Токены палитры находятся в `src/style.css` (`@theme`), там же базовые defaults элементов (`@layer base`). Utility-классы компонентов находятся рядом с JSX; повторяющиеся наборы — в `components/ui/styles.ts`.

## Проверки

```sh
npm run build
npm test
```

Production-сборка находится в `dist/`. Для её размещения нужен reverse proxy `/api` к backend; dev-proxy Vite в production не работает. Авторизация пока отсутствует: backend предназначен для личного доверенного окружения. Публикация не выполнялась.

Выбор даты и времени в формах создания и переноса занятия использует общий `components/ui/DateTimePicker.tsx`: собственная месячная сетка, переход между месяцами, кнопка «Сегодня» и отдельный ввод часов/минут. Формы создания открываются по центру экрана.
