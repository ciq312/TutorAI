# Tutor RAG

Помощник репетитора для быстрой подготовки к занятиям, составления домашних заданий и обратной связи после урока с учётом истории конкретного ученика.

Семантический поиск находит связанные темы и трудности в прошлых занятиях, а LLM использует этот контекст для подготовки черновиков материалов. Репетитор проверяет и редактирует результат.

## Основные сценарии

- **Перед занятием:** получить краткий бриф по ученику и план следующего урока с учётом целей, последних занятий и прошлых трудностей.
- **Домашнее задание:** подготовить задания по пройденным темам с учётом уровня ученика и ошибок, которые стоит отработать.
- **После занятия:** превратить короткие заметки репетитора в понятный фидбек для ученика или родителя.

Подробные сценарии, границы MVP, архитектура, модель данных и план разработки описаны в [PROJECT.md](PROJECT.md).

## Текущее состояние

Проект находится на начальном этапе разработки:

- Есть стартовое приложение FastAPI с маршрутом `GET /`, возвращающим `Hello World`.
- Добавлены Dockerfile и конфигурация Docker Compose для API и PostgreSQL.
- CRUD учеников и занятий, миграции, семантический поиск и генерация материалов пока не реализованы.

Планируемый стек: Python, FastAPI, PostgreSQL с pgvector, SQLAlchemy, Alembic и облачная LLM или Ollama.

## Локальная разработка

Точка входа приложения — `app/main.py`. После настройки зависимостей приложение запускается командой:

```bash
uvicorn app.main:app --reload
```

Адреса при запуске на порту 8000:

- API: http://localhost:8000/
- Swagger UI: http://localhost:8000/docs
- OpenAPI: http://localhost:8000/openapi.json

**Запуск пока требует доработки конфигурации:** `app/core/config.py` импортирует `pydantic-settings`, которого нет в `requirements.txt`. В `docker-compose.yaml` блок `healthcheck` расположен на уровне сервисов вместо вложения в `db`. Файл `.env.example` пока отсутствует. Поэтому готовой инструкции запуска из чистого клона ещё нет.

## Данные и приватность

Планируется хранить историю обучения в собственной PostgreSQL и ограничивать поиск выбранным учеником. При использовании облачных LLM или embeddings соответствующие тексты передаются внешнему провайдеру; локальное хранение само по себе не означает локальную обработку.

Первый MVP рассчитан на личный запуск одним репетитором в доверенной среде. Авторизация и несколько пользователей запланированы отдельно.
